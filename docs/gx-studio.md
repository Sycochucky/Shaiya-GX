# GX Studio

[GX Studio](https://github.com/Spelunkern/GX-Studio) is the standalone desktop
data editor for Shaiya GX. It edits supported loose client files, gameplay
definitions in SQLite and the GX World NpcQuest file. It also includes model,
effect, texture and audio viewers.

- [Download GX Studio beta](https://github.com/Spelunkern/GX-Studio/releases)
- [Setup, editing guides and supported formats](https://github.com/Spelunkern/GX-Studio#readme)
- [Report an editor issue](https://github.com/Spelunkern/GX-Studio/issues)

The game and server build independently of Studio. Older GX archives may
contain the retired Go editor. Use the standalone beta for current Studio
development.
